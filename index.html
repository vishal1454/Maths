Mastering Frequency ($f$) & Cumulative Frequency ($cf$) Distributions

A structured analytical framework for identifying standard class frequencies, "Less Than" cumulative distributions, and "More Than" reverse cumulative distributions—eliminating boundary errors in Mean, Median, and Mode computations.

Section 01 • Core Methodology

The 4-Rule Table Diagnostic System

Apply these four rules sequentially before computing central tendency.

Rule 01 Target: Frequency (f)

Proper Class Limits = Standard Frequency ($f$)

Whenever Class Intervals display explicit upper and lower limits (such as 10–20, 20–30, or 85–100), the count column is always Frequency ($f$)—even if the intervals or counts are listed in descending or mixed order.

Verification Check: Sum of all values equals total sample size ($\sum f = N$).
Rule 02 Target: Standard cf

"Less Than" / "Below" = Standard $cf$

If intervals are phrased as "Less than 20" or "Below 30", the given column is Standard Cumulative Frequency ($cf$). Because totals accumulate downward, values never decrease (they strictly increase or remain constant).

Extraction Formula: Subtract top from bottom (fk = cfk − cfk−1).
Rule 03 Target: Reverse cf

"More Than" / "Above" = Reverse $cf$

If intervals are phrased as "More than 10" or "Above 20", the given column is Reverse Cumulative Frequency. Starting from total $N$, values never increase as you move down the table.

Extraction Formula: Subtract bottom from top (fk = cfk − cfk+1).
Rule 04 Boundary Indicator

The Zero (0) Boundary Giveaway

A cumulative column starting with 0, 5, 12... confirms a "Less Than" distribution. Conversely, a column ending with ...12, 7, 0 confirms a "More Than" distribution.

Boundary Action: Use the 0 row to subtract cleanly, then drop the 0-frequency row.
